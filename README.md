# پلتفرم سراسری «افغان بازار» (Afghan Bazar)
بزرگ‌ترین بازار آنلاین متمرکز خرید و فروش سراسری برای ۳۴ ولایت افغانستان با پشتیبانی از واحد پولی افغانی (AFN)، درگاه‌های پرداخت، رتبه‌بندی ۳ سطحی دکانداران (VIP، ویژه و عادی)، و سیستم احراز هویت پیامکی اپراتورهای ۵‌گانه افغانستان (افغان بیسیم، روشن، اتصالات، ام‌تی‌ان و سلام).

## ساختار پروژه:
- `app/`: اپلیکیشن اندروید نیتیو توسعه‌یافته با Jetpack Compose و Kotlin.
- `backend/`: سرویس‌های REST API با Node.js/Express، پایگاه داده PostgreSQL، Prisma ORM، داکر (`docker-compose.yml`) و کلاینت فلاتر (`afghan_bazar_mobile_main.dart`).

## امکانات:
- پوشش کامل تمام ۳۴ ولایت افغانستان (کابل، هرات، بلخ، قندهار، ننگرهار و...)
- احراز هویت شماره‌های افغانستان (07X)
- سیستم تبلیغات درون‌برنامه‌ای و استوری‌های مگنت
- کیف پول و تراکنش‌های افغانی (AFN)
